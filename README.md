## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18+ or 20+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/your-org/novel-shilai-machine.git

# Navigate to project folder
cd "New folder (2)"

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will start at `http://localhost:5173/`.

### Production Build
```bash
# Compile TypeScript and bundle with Vite
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Production Deployment

### Deploy to Vercel
A `vercel.json` file is already included for seamless single-page application (SPA) routing:
```bash
npm install -g vercel
vercel
```

### Deploy to Netlify
A `netlify.toml` and `public/_redirects` file are included.
Push your repository to GitHub or GitLab and connect to Netlify with build command `npm run build` and publish directory `dist`.
